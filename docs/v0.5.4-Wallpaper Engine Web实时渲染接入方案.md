# Wallpaper Engine Web 实时渲染接入方案

> **v1.0.1 当前行为：** 本文描述的是早期 Web 窗口捕获方案。当前官方 Desktop 插件会为 Scene/Web/Application 打开 Wallpaper Engine 具名窗口，并要求用户在本机 Chrome/Edge 配对页选择该窗口；捕获请求只设置 cursor: 'never'，浏览器可能忽略隐藏鼠标提示。Wallpaper Engine Video 仍直接播放原始 MP4/WebM。详见 [v1.0.1 Desktop 兼容说明](v1.0.1-Desktop兼容说明.md)。

日期：2026-09-25  
状态：v0.5.4 源码、构建、唯一 ZIP 和官方 `web` profile 安装已完成；真实 Wallpaper Engine/浏览器捕获人工验收待完成

## 目标

在 DSH Web 页面背景显示本机 Wallpaper Engine Scene 壁纸的实时渲染结果。Wallpaper Engine 负责执行和渲染 Scene；浏览器通过系统屏幕共享授权捕获用户选中的渲染窗口，并将实时视频作为网页背景。现有直接播放 MP4/WebM 的链路保持原样。

## 实施流程

1. 页面背景设置只对当前已应用的 Wallpaper Engine Scene、Web 或 Application 项目显示渲染控制。
2. 用户点击“打开渲染窗口”后，插件后端只接受已扫描到的数值 Workshop ID，重新从安全缓存中解析项目目录，并在已扫描 Steam 库中确认 Wallpaper Engine 主程序正在运行；没有运行时提示用户先启动，不主动启动或接管主程序。
3. 后端使用 `execFile` 参数数组（`shell: false`）打开项目 `project.json`，附带插件独有、随机生成的 `playInWindow` 名称及目标分辨率；每个插件 Host 最多保留一个活动窗口。
4. 用户再点击“选择渲染窗口并显示”。事件处理器立即调用 `navigator.mediaDevices.getDisplayMedia`，浏览器显示自己的来源选择器；用户手动选择 Wallpaper Engine 具名窗口。仅视频轨进入页面固定背景层，不请求音频，不录制或持久化画面。
5. 停止共享、窗口轨道结束、用户切换壁纸、还原默认背景或关闭页面时，停止本地视频轨并通过同源 API 关闭插件随机具名的渲染窗口。

## 访问边界

- 捕获必须由用户的直接点击触发，每次都由浏览器选择要共享的窗口；插件不能指定、静默读取或保存屏幕捕获授权。
- 开始与关闭接口仅接受 JSON、限制请求大小、校验同源，并且只允许插件进程登记的随机会话名和已扫描的 Workshop ID。
- 只使用 `openWallpaper -playInWindow`；关闭只用 `closeWallpaper -location <插件窗口名>`。不调用全局 `pause` / `stop`，不指定显示器或系统桌面位置。
- 支持 Wallpaper Engine 的 Scene、Web、Application 项目；视频壁纸继续以原 MP4/WebM 字节由现有页面 `<video>` 播放，不经窗口捕获再编码。
- 只实现 DeepSeek 页面背景。设置面板仍显示现有静态预览；减少动态效果时实时捕获隐藏并拒绝新启动。
- 只在 Windows 上提供渲染窗口启动。其他系统保留原有图片/视频背景能力并显示不支持说明。
- Wallpaper Engine 官方命令行要求主程序先运行；集成只向该运行实例发出 `openWallpaper -playInWindow` 与对应具名窗口的 `closeWallpaper` 命令。

## 清晰度、性能与失效回退

- 渲染窗口目标尺寸按屏幕物理像素读取并限制在合理上限；页面显示时用 `object-fit: cover`。窗口捕获由浏览器实时编码，画质会受浏览器与系统编码器影响，可能有少量延迟和额外 GPU 使用；原始视频壁纸仍是最高质量路径。
- 场景动态画面只存于内存，不写入 IndexedDB、插件目录或安装包。
- 用户取消来源选择、选错整屏/标签页、浏览器不支持 `getDisplayMedia`、轨道中断、Wallpaper Engine 未安装或启动失败时，停止当前会话、关闭插件窗口并回到已有静态预览，同时向用户显示明确提示。
- 页面刷新、浏览器关闭或插件卸载时尽力通过 `pagehide` / Host dispose 停止并关闭本插件创建的窗口。浏览器的屏幕共享权限不可持久化；重新加载后需要用户重新点选。

## 验收

- Web 页面里可通过两次明确点击把 Scene、Web、Application 壁纸渲染为实时页面背景。
- 浏览器要求手动选窗口；拒绝权限、错误选择整屏/标签页或分享轨结束时，页面回到静态预览且不留下本插件渲染窗口。
- 切换壁纸与还原背景只关闭插件自己的随机具名窗口；不改显示器当前壁纸、不暂停或停止其他 Wallpaper Engine 壁纸。
- 普通视频壁纸仍直接播放原始文件；设置面板背景、设置存储、余额查询和桌宠不受影响。
- 源码 lint / build 检查；不运行自动测试或实际 Wallpaper Engine 渲染，除非用户另外要求。
