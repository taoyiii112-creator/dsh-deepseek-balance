# v0.5.1 DeepSeek 页面背景接入与实现说明

> **v1.0.1 当前行为：** “减少动态效果”只控制余额滚动、桌宠动画和本地导入视频；Wallpaper Engine Video 继续播放，不受该开关影响。页面不可见时页面层背景暂停；设置打开时同一精确来源共用单层并继续播放，来源不同时暂停页面层视频。本文中的旧版“减少动态效果时暂停背景视频”设计不适用于当前 Wallpaper Engine Video；当前边界见 [v1.0.1 Desktop 兼容说明](v1.0.1-Desktop兼容说明.md)。本文其余 v0.5.1 实现与 profile 状态也是当时的记录，不代表当前交付状态。

## 目标与界面位置

在插件设置的“外观”页，将“DeepSeek 页面背景”和“设置面板背景”作为两个独立设置。页面背景位于整个 DeepSeek Harness 会话界面下层，用户可以选择本地图片、视频，或本机已安装的 Wallpaper Engine 壁纸；胶囊、设置面板、桌宠和页面控件仍正常交互。此功能只改变当前插件作用的 DSH 页面，不修改 Windows 桌面壁纸。

来源入口：`默认背景 / Wallpaper Engine / 本地文件`。选中资源后先预览，由用户点击“应用到页面”；支持恢复默认。两个背景各自保存来源、资源和视觉参数，切换一个不覆盖另一个。

## 动态壁纸支持范围

| 来源 | 页面显示 | 原因与回退 |
| --- | --- | --- |
| Wallpaper Engine 视频壁纸 | 支持原视频文件在页面内静音、循环播放，前提是 DSH 使用的浏览器可解码 | 解码/读取失败时显示该项目静态预览图；不播放音轨 |
| Wallpaper Engine 场景壁纸 | 仅显示静态预览图 | 官方场景通常为 `.pkg` 工程，不能直接当视频/网页嵌入；不声称保留粒子、视差或交互 |
| Wallpaper Engine 网页/应用壁纸 | 仅显示静态预览图 | 不在 DSH 页面运行外部 HTML、脚本或可执行程序 |
| 用户本地图片 | 静态背景 | 预览接受 PNG、JPG、WebP；损坏或不支持时不应用 |
| 用户本地视频 | 可解码时静音、循环播放 | 预览接受 MP4、WebM；失败时保留原背景并给出原因 |

Wallpaper Engine 官方将壁纸分为场景、网页和视频类型，视频壁纸通常是预渲染的 MP4；场景壁纸不能直接导出为视频。[类型说明](https://docs.wallpaperengine.io/)、[已下载壁纸文件说明](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html)、[场景导出说明](https://help.wallpaperengine.io/en/functionality/export.html)。Chrome 官方说明允许静音视频自动播放，但最终仍需用目标 DSH/Chromium 实测。[Chrome 自动播放策略](https://developer.chrome.com/blog/autoplay)。

## 交互与显示规则

- 页面背景铺满会话视口，使用 `cover` 裁切，不挡鼠标点击、输入框、胶囊拖动和桌宠拖动；保留页面原有布局。背景选择和设置面板背景选择各有独立标签，避免误设。
- 页面遮罩初始预览值为 38%，由用户调节；文字、侧栏、输入框保持足够对比度。设置面板自身的透明度与自定义背景单独调节，不随页面背景一起改变。
- 视频默认静音循环；窗口进入后台、页面不可见或用户启用减少动态效果时暂停，并显示静态封面。恢复可见时按设置继续。页面只维持一个动态背景播放器，设置面板选择器用静态缩略图，避免同时解码多路视频。
- 选择 Wallpaper Engine 视频时，由本机插件服务只读列出已安装项目并提供受限制的视频/预览资源；不能把本机任意路径直接暴露给网页，也不把用户壁纸打进插件包。本机 Steam 库位置不能写死；探测不到时让用户指定壁纸目录。壁纸被移除或路径失效时，回退默认背景并提示重新选择。
- 当前机器只读核对的 7 个 Wallpaper Engine 视频项目均有本地 `.mp4` 文件，最大约 321 MB；正式实现应按需流式读取并支持视频请求所需的 Range 响应，不能把整部壁纸视频复制进页面状态或插件安装包。这是本机样本，不代表其他用户的视频编码一定可由其 DSH 浏览器解码。
- 用户自选文件仅保存在用户本机；正式实现需核对图片/视频的解码、体积上限与持久化空间。保留既有本地图片入口。无 Wallpaper Engine 或 DSH 服务与本机桌面不在同一台机器时，仍可使用用户自选文件。

## 当前实现边界

v0.5.1 源码已在 `src/http.js` 与 `src/index.js` 增加 Steam 多库探测、用户登记 Steam 库路径、白名单项目元数据读取、预览/视频 Range 流式路由；`src/appearance-ui.js` 与 `src/client.js` 提供独立的页面/面板背景状态、本地媒体 IndexedDB、静音循环、减少动态效果/页面不可见时暂停及资源失效回退。Steam 库路径登记只保存在本机 DSH 服务进程内，并由当前浏览器本地保存的路径在刷新列表时重新登记。

Wallpaper Engine 文件服务依赖 DSH 官方 WebServer，因此本功能的本机壁纸探测目标是官方 `web` profile；官方 Desktop 的本地路由与 UI 兼容尚未验证。需要真实 DSH 页面检查宿主背景层、主题 token、视频解码及遮罩可读性。不能把“支持视频壁纸”扩大解释成“所有 Wallpaper Engine 动态场景都能原样运行”。

验收时检查：正常页面与窄屏布局、导航切换、背景遮罩可读性、输入/拖动命中、视频静音循环、隐藏/减少动态效果暂停、媒体失败回退、文件移除后的恢复，以及设置面板背景与页面背景互不覆盖。不请求真实 DeepSeek API。
