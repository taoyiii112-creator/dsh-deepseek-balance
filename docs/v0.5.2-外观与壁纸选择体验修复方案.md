# v0.5.2 外观与壁纸选择体验修复方案

> **历史版本档案：** 本文的实现与验收状态截止 v0.5.2；当前安装方式、Wallpaper Engine 播放边界和系统动画开关规则以 [v1.0.1 Desktop 兼容说明](v1.0.1-Desktop兼容说明.md) 为准。

## 目标

基于现有 v0.5.1 实现修复设置面板默认观感、壁纸列表查找与布局、Steam 库选择、胶囊避让和背景图清晰度，并将源码、包内 manifest、说明和唯一本地安装包统一为 v0.5.2。

## 实现方案

1. **默认背景与透明度**：设置面板默认使用随插件已有的透明静态桌宠图 `client/assets/pet/idle.png`（1254×1254 PNG），复用原始像素，不生成压缩副本。默认遮罩不透明度由 62% 降至 35%，滑块范围扩展为 10%–85%；面板底色保持轻薄，文字和控件仍置于前景层。
2. **壁纸列表**：只让壁纸卡片列表在固定高度的区域内纵向滚动。外观页签、搜索框、Steam 库目录输入/浏览/添加控件、背景预览和“应用背景”操作放在列表滚动区外。搜索标题、Workshop ID 和类型；没有匹配结果时显示明确提示。
3. **资源管理器选择目录**：Windows 下“浏览…”按钮通过用户显式点击触发本机文件夹选择对话框；后端只运行固定参数的 Windows PowerShell UI 命令，不把用户输入拼进命令。选择结果仍由既有 Steam 库路径验证逻辑检查；手动路径输入继续保留，非 Windows 系统提示使用手动输入。
4. **避免胶囊遮挡**：拖动范围限制在窗口可视宽度内；拖动开始时记录顶栏现有交互控件的位置，胶囊移动到会挡住按钮、链接或输入控件的区域时停在最近的安全边界。窗口变化时继续夹回视口。
5. **提高背景清晰度**：本地导入的图片继续原样存入 IndexedDB，不缩放或重编码。Wallpaper Engine 壁纸若 `project.json` 的 `file` 指向独立图片文件，则直接以原始文件作为设置面板/页面背景，并沿用受限路径检查与流式 HTTP 服务；视频继续播放原始媒体。没有独立图片文件的场景/网页项目继续使用其本机预览图，不解包或执行 `scene.pkg`/网页代码；界面提示此类项目受原预览素材分辨率限制，可导入原图获得清晰背景。
6. **版本与交付**：只生成 `release/dsh-deepseek-balance-0.5.2-安装包.zip` 一份；不创建临时后缀的第二个 ZIP。更新后回读源码、包内与 profile 两份 manifest、客户端哈希和安装器依赖指向。

## 验收范围

- `npm run lint` 与 `npm run build` 通过；不调用真实 DeepSeek API。
- 检查本地图片没有被二次压缩、Wallpaper Engine 静态原图优先逻辑、视频 Range 播放路径、固定工具区/可滚动搜索列表、Windows 文件夹选择返回值与 Steam 路径校验、胶囊与顶栏控件的碰撞边界。
- 只保留一份 v0.5.2 ZIP，检查 MANIFEST 与包内哈希；按既有本地升级授权安装到真实官方 `web` profile 并回读安装状态。
- 本机 DSH/Chromium 页面验收需确认默认静态照片、透明度、Wallpaper 搜索和滚动、目录浏览、背景清晰度及胶囊避让；真实 API 联调与 GitHub Release 不包含在本任务内。

## 实施记录

- 已将随包 `idle.png` 用作默认面板照片，构建时保留原 2,298,154 字节 PNG；默认遮罩为 35%，滑块范围为 10%–85%。
- 壁纸搜索、独立 280px 滚动列表、固定目录工具区和未匹配提示已实现。
- Windows 目录浏览通过同源 POST 路由启动固定参数 PowerShell `FolderBrowserDialog`；选中后填入路径框，添加动作继续走 Steam Workshop 目录验证。手动输入保留。
- 胶囊移动时将同一顶栏垂直范围的可见按钮、链接、输入控件投影为禁入区，并按最近空闲横向区间夹定位置；初始化与视口缩放也避让。
- 静态 Wallpaper Engine 项目的独立图片文件通过白名单路由以原文件流式提供；没有可用图片原件时继续使用预览图并提示无法靠放大恢复细节。本地文件存入 IndexedDB 时未重编码。
- `npm run lint`、`npm run build` 通过。已生成唯一 v0.5.2 ZIP，并用其中的插件包升级真实 profile；包内清单与 profile manifest/客户端哈希已回读一致。真实 DSH 页面视觉验收、自动测试、真实 API 联调和 GitHub Release 未执行。
