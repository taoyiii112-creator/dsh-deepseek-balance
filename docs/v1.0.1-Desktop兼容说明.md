# v1.0.1 DeepSeek Harness Desktop 兼容说明

日期：2026-10-02
状态：1.0.1 源码与唯一安装 ZIP 通过 GitHub Release 分发。本说明描述实现与验收边界，不代表本机 Desktop profile 已升级。

## 安装与运行范围

本插件继续适配官方 DeepSeek Harness Desktop，不包含或替换 DeepSeek Harness。Desktop 的客户端运行于共享 Web 界面，因此 `client.platform` 保持为 `web`；由 Desktop 主应用的“插件”页面管理独立的 `desktop` profile。不要使用 `--profile web` 安装到另一套 profile，也不要用 CLI 写入 Electron 独占的 `desktop` profile。

安装 ZIP 只包含普通插件 tarball、校验清单和说明。用户可从 [GitHub Release v1.0.1](https://github.com/taoyiii112-creator/dsh-deepseek-balance/releases/tag/v1.0.1) 下载，也可直接通过官方 Desktop 插件页添加公开仓库。用户不需要使用定制 DeepSeek Desktop。

## Wallpaper Engine 类型支持

| 类型 | 当前处理 | 限制 |
| --- | --- | --- |
| Image | 从项目中寻找并展示可验证的原图候选；列表缩略图只用于选择 | 没有可靠原图时，不把低清缩略图冒充原图 |
| Video | 通过 Host Range 路由读取项目原始 MP4/WebM，并在页面直接播放 | 不转码、不二次压缩；画质受源素材和 Desktop 解码器限制 |
| Scene | 优先使用 `project.json`；若清单缺失、损坏或入口不存在，且根目录仅有一个 `.pkg` 并有 preview，则交给 Wallpaper Engine CLI 打开 `.pkg` | `.pkg` 不由插件解包；实时画面需要用户在本机浏览器选择 Wallpaper Engine 窗口 |
| Web | 由 Wallpaper Engine 运行项目入口 | 插件不在 DeepSeek 页面内直接执行项目网页代码；实时画面需用户授权捕获 |
| Application | 逐次确认后由 Wallpaper Engine 加载项目；清单缺少 `type` 时按 `.exe` 项目文件识别 | 插件不直接执行 EXE；实时画面需用户授权捕获 |

Wallpaper Engine 选择、搜索、候选、预览和应用位于独立页面；设置面板可拖动，且没有屏幕边缘的额外箭头。页面与设置面板选择相同的精确背景来源时，共用一个全窗口媒体/捕获层；设置打开时保持动态并显示在高不透明度深色面板后方。

Scene、Web、Application 需要 Windows 本机 Desktop、Wallpaper Engine 和 Chrome/Edge。应用壁纸时，插件打开本机配对页；用户点击“开始共享”，再从系统窗口选择器选择页面给出的 Wallpaper Engine 具名窗口。画面通过本机 WebRTC 返回插件，不录制、不上传。捕获请求只设置 `cursor: 'never'`；浏览器可能忽略该提示，所以共享画面仍可能出现系统鼠标。壁纸内容自身绘制的指针也不受该请求控制。重新应用时需重新打开配对页并授权。

## 安全与数据边界

- API Key 通过 DeepSeek Harness 本机 `credentials` 服务读取，不进入客户端 bundle、日志或安装包。
- 壁纸项目只从配置的本机 Steam Workshop 目录读取；客户端不接收绝对路径。
- Application 每次启动前都需明确确认；插件不直接执行用户提供的 EXE。
- 不需要定制 Desktop Shell、Shell 补丁或便携 Desktop 包。
