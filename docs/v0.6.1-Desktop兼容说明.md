# v0.6.1 DeepSeek Harness Desktop 兼容说明

日期：2026-09-27

> **历史快照：** 本文以下内容只记录 v0.6.1 的兼容和 profile 状态，不代表当前插件行为。当前版本为 v1.0.1；捕获页只在 getDisplayMedia() 请求中设置 cursor: 'never'，不会因鼠标状态不明而中断共享。详见 [v1.0.1 Desktop 兼容说明](v1.0.1-Desktop兼容说明.md) 和 [本机浏览器壁纸捕获历史方案](v0.6.2-官方Desktop本机浏览器壁纸捕获方案.md)。

## 兼容方式

官方 DeepSeek Harness Desktop 使用独立的 `desktop` profile，并加载共享的 Harness Web 应用。插件包因此继续声明 `dsh.client.platform: web`：它指的是客户端运行平台，不代表安装到 `web` profile。将该字段改为 `desktop` 会使客户端插件与共享 Web 渲染界面脱离。

本版保留余额胶囊、React 客户端插槽、Host 端 `webServer` 与 `credentials` 注入，以及本地背景和 Wallpaper Engine 功能。旧的自制安装器和诊断器固定调用 npm CLI 并指定 `--profile web`，不适用于 Desktop 的隔离 profile；v0.6.1 移除这些脚本，改由 Desktop 插件管理器安装本地 `.tgz`。

## 安装与下载

将安装 ZIP 解压到固定目录，在 Desktop 左侧栏打开主“插件”页面，选择添加插件并填写 `.tgz` 的完整本地路径。安装成功后启用 bundle；按页面提示重启应用。设置页里的插件清单是只读视图，不承担安装操作。客户端 `platform: web` 是共享 Web 客户端的声明；安装目标仍是 Electron 独占的 `desktop` profile。

截至 2026-09-27，此版本没有公开 Release 下载地址。要让其他人使用，维护者需要直接发送唯一安装 ZIP；工作区的 `release/` 路径只在维护者电脑可访问。公开下载需要另行创建正式 Release。

本地 tarball 安装可能会把 `.tgz` 路径写入 Desktop profile 的 `package.json` 和 lockfile。应从稳定目录安装并保留 `.tgz`，避免将来源文件放在可能自动清理的临时目录。

### 常见失败原因

- `dsh plugin --profile desktop ...` 返回 `profile "desktop" is managed exclusively by the Electron application`：这是官方 CLI 的所有权保护。Electron 应用独占该 profile；退出 CLI 安装，改用 Desktop 主应用“插件”页面。
- `dsh plugin --profile web ...`：命令操作的是 Web profile，不是 Desktop profile。即使命令成功，Desktop 也不会因此加载到该 bundle。
- 管理器提示路径无效或 bundle 无效：确认传入的是 ZIP 内的 `.tgz` 完整路径；不要填写外层 ZIP 或 `.sha256`，并核对 tarball 哈希。
- pnpm 显示网络/包源、磁盘空间、目录权限或依赖脚本问题：从管理器失败详情查看 Host/pnpm 输出并按对应原因修复后重试。Desktop 插件管理器通过 Electron 自带的 pnpm 执行 profile 包操作，不要求系统 PATH 中另装 pnpm。
- 安装已完成但没有运行：确认选择了启用，检查 bundle 错误状态，并按提示重启。安装成功本身不能证明 bundle 已成功激活；应继续确认会话顶栏和插件页面错误信息。

本机本轮通过 CLI 尝试 Desktop profile 被上述保护拒绝；之后用户已手动从 Desktop 插件页安装。profile 只读回读显示包和插件 manifest 均为 `0.6.1`，bundle 已加入启用列表。页面运行、余额请求和壁纸播放仍需单独人工验收。

## Wallpaper Engine：Desktop 行为

- Video 类型使用项目中的原始 MP4/WebM 文件，由 Desktop 页面内的 `<video>` 直接播放，Host 以 HTTP Range 字节流提供原文件；不转码、不截图、不二次压缩。高分辨率播放要求创意工坊项目本身包含高分辨率视频，且 Desktop 解码器支持该文件编码。
- 壁纸列表的像素尺寸描述静态回退图，不是 Video 文件的分辨率；如果要判断动态视频是否为 1080p/4K，应查看 Wallpaper Engine 项目的原始视频文件属性。
- `prefers-reduced-motion: reduce`（系统“减少动态效果”）是选择性控制：余额滚动、桌宠动画和本地导入视频遵循此偏好；用户主动选择的 Wallpaper Engine Video 继续播放，不受该开关影响。页面隐藏或打开设置面板时，插件页面层背景仍会暂停以节省资源；打开设置使用同一个视频节点保留当前高清帧，不切换成 `/background` 预览。以上行为都不会暂停或修改 Wallpaper Engine 桌面壁纸。
- Scene、Web、Application 类型在当前已安装 v0.6.1 profile 中使用本机可用的独立背景图或明确标注的预览回退；工作区插件侧会递归检查项目图片并只读分析 Web 入口引用，但它们不会在本版 profile 中实时运行 Wallpaper Engine 场景。
- 已移除旧版 `-playInWindow` 渲染窗口、配套打开/关闭 API 和浏览器 `getDisplayMedia` 捕获流程。因此不会额外启动壁纸窗口，也不会出现浏览器窗口共享授权或重复鼠标。
- Scene 原生播放尚未在当前已安装 v0.6.1 Desktop 中完成。v0.6.1 profile 仍没有 Scene/Web/Application 实时画面能力；插件渲染进程本身不获得原始 Electron IPC、文件系统访问或 shell。

## 本机检查依据

- `D:\DSH\DeepSeek Harness.exe` 的文件版本为 `0.1.7-rc.2`；这是本机检查时的安装版本。
- 本机 Desktop profile 目录 存在，已回读 `dsh-deepseek-balance` 的 `package.json` 和 `dsh.plugin.json` 均为 `0.6.1`；`dsh.profile.bundles` 含该 bundle。
- 本机安装记录引用一个临时目录下的本地 `.tgz`。为保证将来可修复/重新安装，应保留这个来源文件；后续安装建议先将 ZIP 解压到固定目录。
- v0.6.1 的 `package.json` 与 `dsh.plugin.json` 版本一致，并都将客户端平台标为 `web`。

## 验收边界

官方 Desktop 文档说明 Desktop 使用独立 profile，并由 Desktop 内的共享插件管理器管理插件；插件规范仍要求 `client.platform: web`。官方 Electron Shell 仅向页面开放指定 preload bridge，明确不向渲染进程提供原始 IPC、文件系统访问、shell 或任意 pnpm 参数。当前插件仅使用公开的 Web 客户端与 Host 插件接口。

用户已手动安装插件，但只读 manifest/profile 检查不能替代 Desktop 页面验收。以下项目仍待人工确认：插件是否实际加载到会话顶栏、Host 路由与凭据服务是否可用、余额刷新与滚动终态、设置面板和本地图片/视频背景、Video 壁纸原视频播放。Scene/Web/Application 捕获流程属于 v0.6.2 插件实现，未进入当前 v0.6.1 profile，不能据此认定本机 profile 已支持。

第三方桌面版不在此兼容声明范围内。DeepSeek Harness 为开发预览软件，兼容性以具体 Desktop 版本实机验收为准。
