# v0.6.2 Desktop 壁纸与可拖动设置面板方案

日期：2026-09-30  
状态：插件侧五类 Wallpaper 项目处理（含 `.pkg` Scene 回退）、独立 Wallpaper 选择页、可拖动设置面板、本机窗口捕获流程和同源背景共用已实现。用户已确认本机共享可显示壁纸。鼠标校验逻辑已按要求回退到 17:47 首轮捕获行为，只请求 `cursor: 'never'`，不保证浏览器会隐藏鼠标。没有逐项验收所有类型，Codex 未回读 profile；v0.6.2 未发布为 GitHub Release，后续 1.0.1 Release 见 [安装说明](../INSTALL.md)。

## 目标

用户继续使用官方 DeepSeek Harness Desktop。v0.6.2 以普通插件实现 Wallpaper Engine Image、Video、Scene、Web、Application 五类壁纸，不构建或替换 DeepSeek Desktop。

设置面板为约 560px 的可拖动悬浮卡片，拖动标题栏可移动，位置保存在本机 profile；不显示屏幕边缘的额外折叠箭头。选择 Wallpaper Engine 后单独打开全屏选择页；搜索、壁纸列表、候选来源、原图/原视频预览和应用操作都在该页完成。设置面板本身只保留进入 Wallpaper 页的入口。

页面和设置面板选择同一精确来源时（本地图片按 asset ID；Wallpaper 按库、Workshop ID、素材候选、媒体类型和原生渲染会话），页面层只创建一次并铺满整个窗口。设置打开时不暂停这层，也不另建或重新裁切背景；卡片使用约 94% 不透明的深色玻璃底和轻微模糊，画面仍透出少量，文字与控件保持清晰。页面遮罩上限临时降到 18%。来源不同则仍分别渲染；卡片使用约 82% 深色底，设置打开时页面视频暂停。

## 五类壁纸实现

| 类型 | 来源与实际运行方式 | 使用边界 |
| --- | --- | --- |
| Image | 读取项目中的原始图片；必要时使用明确标注的 preview 回退 | 不把列表 thumbnail 当原图 |
| Video | 从项目原始 MP4/WebM 通过 HTTP Range 播放 | 同源页面/面板共用单一全窗口视频；不同来源时设置打开暂停页面层；用户主动选择的 Wallpaper Engine Video 不受系统减少动态效果开关影响 |
| Scene | Wallpaper Engine CLI 优先以项目 `project.json` 打开随机命名的窗口；清单缺失、结构损坏或 Scene 入口文件不存在时，在根目录有唯一 `.pkg` 与 preview 的情况下直接打开 `.pkg` | `.pkg` 不解包；preview 只作选择前静态预览，捕获由浏览器窗口选择器完成 |
| Web | Wallpaper Engine CLI 打开项目入口 HTML 文件 | 浏览器不直接执行项目网页代码；由 Wallpaper Engine 运行 |
| Application | `project.type` 未填写时，按 `.exe` 项目文件识别；要求每次勾选信任确认，再由 Wallpaper Engine 加载项目 `project.json` | 插件不直接执行 EXE；仍需按具体项目人工验收 |

Image/Video 的文件发现、字节 Range 和 Web 本地引用扫描都限制在已配置的 Steam Workshop 项目目录。返回客户端的是短 ID、类型、分辨率和本机路由，不返回绝对路径。

## Scene/Web/Application 本机捕获流程

1. 插件 Host 校验 Workshop ID、库标识、项目类型、项目文件路径和尺寸；Application 还要确认信任。
2. Windows Host 通过 Wallpaper Engine 官方 CLI 在唯一的 `DSH Balance` 名称下打开项目窗口，并通过系统默认 URL handler 打开 localhost 配对页。
3. 用户在最新版 Chrome 或 Edge 点击共享，并严格按配对页显示的完整名称，在系统窗口选择器中选取对应的 Wallpaper Engine 窗口。
4. 浏览器通过本机 WebRTC 将窗口画面送回插件渲染层。信令仅经当前本机 Host 的 loopback origin；没有 STUN/TURN、云端中继、录制或上传。
5. 捕获页每 30 秒发送会话心跳；关闭页面、停止共享、切换背景、插件退出或会话过期时释放媒体轨并关闭对应的 Wallpaper Engine 窗口。

启动参数遵循 Wallpaper Engine 官方的 `openWallpaper -file ... -playInWindow ... -width ... -height ...` 和 `closeWallpaper -location ...` 接口：[官方命令行说明](https://help.wallpaperengine.io/zh/functionality/cli.html)。

这个方案不需要 DeepSeek Harness Shell 源码。浏览器选择器会让用户选择窗口，但标准 MediaStreamTrack 不提供可验证的窗口标题或 PID；插件会明确显示目标名称和提示，无法阻止用户误选其他窗口或整个屏幕。

## 可拖动设置面板与独立 Wallpaper 页

- 设置面板可拖动，不固定在屏幕右侧；页面和面板外观来源可分别设置。
- 点击 Wallpaper Engine 入口后进入单独选择页，不在设置面板内显示壁纸列表、搜索框或候选项。
- 独立页展示 Image、Video、Scene、Web、Application 类型标签，并可搜索标题、Workshop ID 和类型。Image 使用验证到的项目原图；Video 预览直接播放原文件；Scene/Web/Application 的列表图只供选择，应用后由 Wallpaper Engine 实时渲染。
- 列表的选中描边代表右侧正在查看的壁纸；“当前使用”标签代表已保存并生效的壁纸。每次重新打开选择页都清除上次未应用的临时选择，避免旧 Scene 详情与已应用 Video 行同时产生误导。
- Image 没有原图时会禁用以缩略图应用；Image 存在多个候选时需在独立页明确选择。
- Application 选择和应用前展示逐次确认；切换背景或恢复默认时释放旧捕获会话。
- 设置只存储在当前本机 DeepSeek Harness profile，不同步到其他设备。

## 失败处理与安全边界

- Image/Video 与 Scene/Web/Application 分开处理；缺少可运行入口文件、Wallpaper Engine 未运行、WPE 窗口启动失败、默认浏览器配对页启动失败、浏览器拒绝共享、窗口选择错误或 WebRTC 连接失败时，不把 preview 谎称为实时原生画面，也不覆盖当前已应用背景。WPE 窗口和配对页分别报错；捕获过程中展示等待状态；WebRTC 失败不再固定等待完整 120 秒；失败时回收本次随机命名窗口。
- Host 只接受受限项目 ID、类型、尺寸和固定参数；校验所有目标文件位于当前 Workshop 项目目录且没有符号链接路径逃逸。
- 所有外部进程均通过固定可执行文件和参数数组启动，`shell: false`；Application 内容只交由用户确认后的 Wallpaper Engine 加载。
- 信令会话使用随机 UUID、同源校验、no-store 和受限 CSP；过期会话由 Host 定时回收。
- 远程 Harness Web Host、非 Windows Host、禁用 localhost 捕获的浏览器策略不支持 Scene/Web/Application 实时画面。
