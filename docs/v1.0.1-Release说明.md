# DeepSeek Harness API 余额插件 1.0.1

## 更新内容

- 在会话顶栏显示 DeepSeek API 余额，支持多币种、手动刷新、定时刷新和余额变化提示。
- API Key 通过 DeepSeek Harness 本机 `credentials` 服务读取，不写入浏览器 bundle、日志或安装包。
- 设置面板可拖动；Wallpaper Engine 壁纸在独立选择页中浏览、搜索、预览和应用。
- 包含 Image、Video、Scene、Web、Application 五类 Wallpaper Engine 处理流程。Image 使用可验证的项目原图；Video 播放本机原始 MP4/WebM；Scene/Web/Application 通过 Wallpaper Engine 窗口及用户授权的本机 Chrome/Edge 窗口捕获显示。
- 继续使用官方 DeepSeek Harness Desktop，不需要定制 Shell 或替换官方应用。

## 安装

从本页下载唯一资产 `dsh-deepseek-balance-1.0.1-安装包.zip`，解压后根据其中的 `INSTALL.md`，在官方 DeepSeek Harness Desktop 的“插件”页安装 `.tgz`。也可以直接添加公开 GitHub 仓库：<https://github.com/taoyiii112-creator/dsh-deepseek-balance>。

## 兼容与验收说明

- Scene/Web/Application 需要本机 Windows DeepSeek Harness Desktop、Wallpaper Engine 和最新版 Chrome/Edge；用户每次应用时都需在浏览器窗口选择器中选择目标窗口。Application 还需逐次确认。
- 捕获请求只设置 `cursor: 'never'`；浏览器可能忽略该提示，系统鼠标仍可能出现在共享画面中。
- 代码覆盖五种 Wallpaper 类型，但没有对所有壁纸项目逐项进行实机验收。构建与打包检查不代表已在用户的 Desktop profile 中安装或运行。
- 本次运行 `npm run lint`、`npm run build` 和打包/清单校验；自动测试未运行。
