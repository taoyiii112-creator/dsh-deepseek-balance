# v0.4.7 兼容性说明

> **历史版本档案：** 本文的安装器和 `web` profile 描述只适用于 v0.4.7，不适用于当前 v1.0.1 Desktop 安装。当前操作见 [安装说明](../INSTALL.md) 和 [v1.0.1 Desktop 兼容说明](v1.0.1-Desktop兼容说明.md)。

状态：源码与自动测试完成；真实 DSH 页面和 Desktop 验收待进行。日期：2026-09-25。

本插件依赖的不是 npm 或源码下载方式，而是运行时接口：DSH/Cordis 插件加载、Host 的 `webServer` 与 `credentials`、客户端模块加载、React 18，以及 `conversation.session.header.utilities` 会话顶栏插槽。插件元数据当前声明 `client.platform: web`；分享包安装器固定使用 `--profile web`。导入桌宠还需要页面支持 IndexedDB、Blob URL、Canvas、透明 WebM/图片解码。

| 运行方式 | 目前判断 | 安装/验收边界 |
| --- | --- | --- |
| 官方 npm `npx @deepseek-ai/dsh web` | 目标环境；0.4.6 曾在官方 Web 实机安装，0.4.7 目前只有构建、自动测试和隔离安装回读 | 安装到对应 `web` profile；0.4.7 需页面验收 |
| 官方源码构建后 `pnpm dsh web` | 预期可适配同版 Web，但不保证任意提交或版本 | 检查源码所用版本、`DSH_HOME` 与 Web profile；重新构建后做启动和页面验收 |
| 官方 DeepSeek Harness Desktop | 官方文档说明它封装完整 Web 应用并使用共享插件管理能力，因此有适配路径；本插件尚未验收 | Desktop 独占 `desktop` profile；当前安装器只写 `web`，不能据此宣称已安装 Desktop |
| 第三方桌面版 | 无法按“桌面版”名称承诺兼容 | 需逐项确认它实际运行的是 DSH Host、提供上述服务与插槽、允许安装对应 profile，并支持本地媒体 API |

DeepSeek Harness 官方仓库明确提示当前为开发预览期，可能出现破坏兼容的变更。因此不能承诺“所有版本都能用”；兼容范围应以实际版本组合的启动、插件加载、设置、余额路由、素材导入与页面交互测试为准。

官方依据：

- [DeepSeek Harness 官方 README：npm 与源码启动方式、开发预览期说明](https://github.com/deepseek-ai/deepseek-harness)
- [官方 Desktop README：完整 Web 应用、独立 desktop profile、共享插件管理](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md)

本项目当前没有安装、改动或测试用户的真实 Desktop profile，也没有请求真实 DeepSeek API。若将来要支持某个第三方桌面版，应先取得其准确项目、版本与插件接口资料，再列出所需适配，不能仅替换安装路径。
