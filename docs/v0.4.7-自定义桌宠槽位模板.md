> **历史版本档案：** 下方页面验收状态和实现范围仅描述 v0.4.7 当时情况；当前版本为 v1.0.1。最新 Desktop 安装和验收状态见 [项目 README](../README.md) 与 [v1.0.1 Desktop 兼容说明](v1.0.1-Desktop兼容说明.md)。

状态：已按此模板实现首版编辑器；真实页面交互仍需验收。对应 [v0.4.7 胶囊内置设置与桌宠方案设计](v0.4.7-胶囊设置与桌宠方案设计.md)。

一个桌宠方案始终保留 5 个基础槽位；自定义槽位最多添加 5 个，方案合计最多 10 个。空的基础槽位仍计入总数。方案最多保存 3 个用户自定义版本，与槽位数量限制分别计算。

## 添加时的空白表单

| 字段 | 填写处 | 要求 |
| --- | --- | --- |
| 场景名称 | `__________` | 如“挥手”；同一方案内不可重名 |
| 透明媒体 | `选择本地文件` | 透明 VP9 WebM、PNG、WebP 或 APNG；只接收通过格式和透明度验证的文件 |
| 静态封面/后备 | `选择图片` 或 `从视频提取` | 视频场景必须有透明静态后备；图片场景可使用原图 |
| 触发规则 1：当 | `选择已接入事件：__________` | 如“可比较余额增加”“本地时间处于某时段”“桌宠点击”；界面只列出实际可用事件 |
| 触发规则 1：且 | `添加条件：字段 __ / 运算 __ / 值 __` | 可添加多个条件；同一规则内必须全部满足 |
| 更多触发规则 | `＋ 添加规则` | 任意一条规则满足即可触发；不添加规则时槽位只保存为草稿 |
| 播放控制 | `单次 / 至状态结束；冷却 __；优先级 __` | 循环必须有退出条件，冷却与优先级处理重复触发和规则冲突 |
| 基础动作 | `替代同事件基础动作 / 基础动作播完后再播` | 默认替代，让命中的自定义规则立即生效；后一项串行播放 |

表单底部提供“播放预览”“取消”“保存槽位”。“播放预览”独立于触发规则，不是固定触发方式；预览不会修改当前方案。保存前显示 `当前槽位数/10`，验证通过后才占用名额。达到 10/10 时禁用添加入口。编辑与删除只能作用于用户添加的槽位，不能删除 5 个基础槽位。

## 填写示例

| 字段 | 示例 |
| --- | --- |
| 场景名称 | 开心一下 |
| 透明媒体 | `happy.webm` |
| 静态封面/后备 | `happy.png` |
| 触发规则：当 | 可比较余额增加 |
| 触发规则：且 | 币种为 CNY，且精确增加额大于或等于 10.00 |
| 播放控制 | 单次播放；冷却 5 分钟；普通优先级 |
| 基础动作 | 替代同事件的“余额增加”基础动作 |

这个例子是用户自己选择余额事件并填写币种与金额条件，不是从“点击/待机/预览”三个预设中选一个。金额条件使用已有精确十进制比较结果；首次加载、失败或币种不可比较时不会误触发。“开心一下”只是场景名称，不会自行创建事件。尚未接入的业务来源（例如 Harness 收到聊天消息）不能靠填写名称或脚本启用，应先验证来源并纳入可用事件目录。
